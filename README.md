# 🤖 J.A.R.V.I.S. for Mobile Termux (Android)

안드로이드 스마트폰의 **Termux** 환경에서 동작하는 아이언맨 스타일 **J.A.R.V.I.S. AI 비서** 시스템입니다.

모바일 단말기의 하드웨어(배터리, 손전등, 알림, 카메라 비전, 위치/날씨, 오디오, 타이머, 무추적 웹 검색) 제어 기능과 구글 Gemini LLM의 Function Calling(도구 호출)을 결합하여, 사용자의 음성 및 텍스트 명령에 맞춰 스마트폰을 제어하고 스마트하게 대화합니다.

---

## 🎙️ 연속 음성 대화 모드 (Hands-Free Voice Mode)

버튼이나 키보드를 누를 필요 없이 **입(음성)으로만 연속으로 명령하고 자비스가 음성으로 대답하는 완전 자동 모드**입니다.

### 실행 방법
```bash
# 1) 시작할 때 바로 음성 전용 모드로 켜기
python main.py --voice

# 2) 이미 터미널이 켜져 있을 때 음성 모드로 전환하기
/handsfree
```

### 동작 특징
- 자비스가 *"Hands-free voice mode activated, Sir. I am listening."* 하고 음성으로 인사하며 마이크 입력을 자동 대기합니다.
- 입으로만 명령하면 하드웨어를 제어하고 대답을 음성(TTS)으로 알려준 뒤, **곧바로 다음 음성 명령을 다시 수신**합니다.
- 음성 대화를 종료하려면 *"종료"*, *"그만"*, 또는 *"stop"* 이라고 말하면 됩니다.

## 🔒 보안 및 사생활 보호 정책 (Security First)

- **전화/SMS 기능 제외**: 불필요한 과금이나 무단 문자/전화 발송 악용 가능성을 차단하기 위해 전화 및 SMS 발송 기능은 완전히 제외되어 안전합니다.
- **카메라 임시 사진 파기**: 자비스가 시각 분석(`analyze_camera_photo`)을 위해 사진을 촬영한 후 Gemini AI 분석이 끝나면 **즉시 스마트폰 메모리에서 파기(삭제)**합니다.
- **추적 없는 무추적 보안 검색**: DuckDuckGo 기반 실시간 정보를 검색하여 개인정보 추적이 발생하지 않습니다.
- **무료 오픈 날씨 API**: 카드 등록이나 개인정보가 필요 없는 Open-Meteo 오픈소스 API를 활용합니다.

## 📱 사전 준비 사항 (스마트폰 세팅)

> [!IMPORTANT]
> **구글 플레이스토어의 Termux는 버전 업데이트가 중단되었습니다.**
> 반드시 **F-Droid**를 통해 앱을 설치해야 정상 작동합니다.

1. **F-Droid 설치 및 앱 다운로드**:
   - [F-Droid 공식 사이트](https://f-droid.org/) 접속 후 F-Droid APK 다운로드 및 설치
   - F-Droid 검색 창에서 **Termux** 검색 후 설치
   - F-Droid 검색 창에서 **Termux:API** 검색 후 설치 (하드웨어 제어 필수 앱)

2. **Termux:API 권한 부여**:
   - 스마트폰 `설정` -> `애플리케이션` -> `Termux:API` 진입
   - **마이크, 알림, 카메라(손전등/비전 분석용), 위치(GPS)** 등 권한 허용

## 🚀 설치 방법

Termux 앱을 연 후 아래 명령어들을 순서대로 실행합니다:

```bash
# 1. 저장소 클론 또는 프로젝트 폴더 이동
git clone https://github.com/<your-username>/javis.git
cd javis

# 2. 자동 설치 스크립트 실행 권한 부여 및 실행
chmod +x setup_termux.sh
./setup_termux.sh
```

## 🔑 Gemini API 키 설정

1. [Google AI Studio](https://aistudio.google.com/)에서 무료 **Gemini API Key**를 발급받습니다 (신용카드 등록 불필요).
2. `javis` 폴더 안의 `.env` 파일에 API 키를 입력합니다:

```bash
echo "GEMINI_API_KEY=your_actual_gemini_api_key_here" > .env
echo "JARVIS_MODEL=gemini-2.5-flash" >> .env
```

## 💻 실행 방법 및 터미널 명령어

```bash
# 일반 터미널 인터페이스로 실행
python main.py

# 연속 음성 모드로 즉시 실행
python main.py --voice
```

### 🛠️ 터미널 내 주요 명령어
- `/handsfree` 또는 `/hf` : 연속 핸즈프리 음성 대화 모드 켜기 (말만 하고 대답듣기 반복)
- `/voice` : 단발성 1회 마이크 음성 인식 입력
- `/speak` : 자비스의 응답을 안드로이드 내장 음성(TTS)으로 출력 토글
- `/status` : 자비스 시스템 진단 및 스마트폰 배터리/네트워크 상태 점검
- `/clear` : 화면 정리
- `/exit` 또는 `exit` : 자비스 종료

## ⚡ 지원되는 14가지 모바일 제어 기능

J.A.R.V.I.S.에게 자연스럽게 말하거나 입력하면 스마트폰 하드웨어를 알아서 제어합니다:

1. 🎙️ **연속 음성 대화 (Hands-Free)**: `"python main.py --voice"` 또는 `/handsfree` (입으로만 말하기)
2. 📷 **카메라 비전 분석**: `"자비스, 앞에 보이는 거 촬영해서 설명해줘"` (Gemini Vision 연동 후 파일 즉시 파기)
3. 📍 **GPS & 날씨 정보**: `"지금 내 위치 날씨 어때?"`
4. ⏰ **타이머 & 카운트다운 알람**: `"3분 뒤에 타이머 울려줘"`
5. 🎵 **오디오 파일 재생**: `"다운로드 폴더에 있는 음악 재생해줘"`
6. 🌐 **보안 웹 검색**: `"최신 뉴스 검색해줘"` / `"파이썬 최신 버전 정보 알려줘"`
7. 🔋 **배터리 확인**: `"지금 스마트폰 배터리 몇 프로 남아있어?"`
8. 🔦 **손전등 제어**: `"손전등 좀 켜줄래?"` / `"손전등 끄렴."`
9. 🔔 **알림 생성**: `"메모 알림 하나 상단바에 띄워줘"`
10. 💬 **토스트 팝업**: `"화면에 토스트 메시지 띄워줘"` (화면 하단 스르륵 나타났다 사라지는 팝업)
11. 📋 **클립보드 읽기/쓰기**: `"클립보드 내용 읽어봐"`
12. 📶 **Wi-Fi 점검**: `"현재 연결된 와이파이 상태 알려줘"`
13. 📳 **스마트폰 진동**: `"스마트폰 진동 울려봐"`
14. 🗣️ **음성 TTS 대화**: `/speak` 켜기/끄기
